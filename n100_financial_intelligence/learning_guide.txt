Capstone Project Guidelines 
The Capstone Project is a real-world data analytics project assigned to you in Week 1. It will be in the Fintech domain. You must submit a complete notebook + Flask API + report. 
✓ Exploratory Data Analysis (EDA) with visualizations on the provided financial dataset ✓ Data cleaning pipeline using Pandas (handle missing values, outliers, data types) ✓ SQL queries in PostgreSQL to answer 5+ business questions from the dataset 
✓ Statistical insights: trends, correlations, anomaly detection 
✓ A simple Flask API (minimum 2 endpoints) that serves data insights as JSON 
✓ Optional (bonus): A basic ML model (regression or classification) on the dataset ✓ Final report: PDF or Jupyter Notebook with narrative, charts, and findings 
✓ GitHub repository with clean commit history, README, and requirements.txt
